# AntiCrash

A 1.8.9 forge mod that fixes some crashes

## Download

1. download [this zip file](https://nightly.link/ManInMyVan/AntiCrash/workflows/build/main/AntiCrash%201.8.9-forge.zip)
2. unzip it
3. pick a jar file
   - The only difference between the two jar files is that `-lite`
   does not bundle Mixin, which reduces the file size, however, if you use `-lite`,
   another mod MUST provide Mixin, or the game will not load,
   as 1.8.9 forge does not bundle the necessary classes for mixins to function.
4. put it in your mods folder
