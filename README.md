# AntiCrash

A 1.8.9 forge mod that fixes some bugs

fixes:
https://bugs.mojang.com/browse/MC/issues/MC-36933
https://bugs.mojang.com/browse/MC/issues/MC-44140
https://bugs.mojang.com/browse/MC/issues/MC-62975
https://bugs.mojang.com/browse/MC/issues/MC-82677
https://bugs.mojang.com/browse/MC/issues/MC-85109
invalid GameProfiles causing the game to crash
Forge allowing cactus and mushrooms to be placed on the wrong blocks
Chest/Anvil collision boxes being based on the one you last looked at (Optionally)

## Download

1. download [this zip file](https://nightly.link/ManInMyVan/AntiCrash/workflows/build/main/AntiCrash%201.8.9-forge.zip)
2. unzip it
3. put the jar in your mods folder
